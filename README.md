# ForceFire Extintores e Segurança

Site institucional e comercial da **ForceFire Extintores e Segurança** — venda, recarga e manutenção de extintores, mangueiras, sinalização e regularização AVCB/CLCB em Ribeirão Preto, região e todo o Estado de São Paulo.

Site estático, sem build: **HTML5 + CSS3 puro + JavaScript nativo (ES6+)**, sem frameworks.

## Estrutura

```
index.html      Documento principal
css/style.css   Design system completo
js/main.js      Engine de interatividade e motion
img/            Logo (SVG), favicon e fotos
robots.txt      Indexação
sitemap.xml     Mapa do site
```
